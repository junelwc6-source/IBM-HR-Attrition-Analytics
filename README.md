# Employee Attrition Analysis and Prediction Using Python and Power BI

## Project Overview

This capstone project uses the IBM HR Analytics dataset to analyse employee attrition patterns, identify factors associated with employee turnover, and develop a predictive model to estimate employee attrition risk.

The findings aim to support data-driven workforce planning and employee retention strategies.

## Problem Statement

How can employee data be analysed to understand attrition patterns, identify factors associated with employee turnover, and predict attrition risk to support proactive workforce planning?

## Research Questions

1. What is the overall employee attrition rate, and how does it vary across departments, job roles and employee demographics?
2. How are job satisfaction, work-life balance and overtime associated with employee attrition?
3. What relationships exist between employee compensation, length of service, career progression and attrition?
4. Which employee-related factors are the strongest predictors of attrition?
5. How can machine learning and Power BI be used to predict attrition risk and support proactive workforce planning?

## Tools and Technologies

- Python – Data cleaning, exploratory data analysis, visualisation and predictive modelling
- Power BI – Interactive dashboards and business insights
- GitHub – Project documentation and version control
